# No LLM policy

LLM usage in EPNix is strictly forbidden.
Open source is about humans,
use humans instead of LLMs.

Contributions generated by LLM,
partially or in full,
are forbidden.

Taking the output of an LLM and rephrasing it is strictly forbidden,
please don't hide your LLM usage
and respect the contribution policy.

Using agents to automate creating issues or PRs is forbidden.

Using LLM generated text for communication is forbidden.
If you have trouble with English,
you can post your message in your native language
and let readers use their own translation tools of choice.

We know this can't be reasonably enforced,
but for brainstorming ideas,
understanding a piece of EPNix code,
or debugging,
please avoid using LLMs.
Use one of the communication channels mentioned in <project:#getting-help>
to brainstorm or ask your questions,
we'd be more than happy to help.
